# CSV Insight Pro 📊

A simple and professional CSV data analysis dashboard built with Python, Pandas and Streamlit.

## Features

- Upload CSV files
- Preview dataset
- Show number of rows and columns
- Detect missing values
- Detect duplicate rows
- Show column data types

## Technologies

- Python
- Pandas
- Streamlit

## How to run

```bash
pip install -r requirements.txt
streamlit run app.py
